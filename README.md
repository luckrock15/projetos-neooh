## Projeto 01 — Rock Street | Agente de IA
Assistente virtual de briefing de Marketing para uma loja fictícia de camisetas de rock e moda alternativa.

### Ferramentas utilizadas
- n8n — automação e criação do fluxo
- Google Gemini — modelo de inteligência artificial
- Simple Memory — memória de conversação
- Calculator — ferramenta de cálculos

### Funcionalidades
- Coleta informações para campanhas de Marketing.
- Mantém o contexto da conversa.
- Organiza briefings para revisão humana.
- Evita confirmar descontos e promoções sem validação.

### Testes realizados
Foram realizadas três interações para avaliar o contexto, além de um teste que identificou uma resposta inadequada sobre desconto de 70%. As regras foram corrigidas e a resposta foi testada novamente com sucesso.
